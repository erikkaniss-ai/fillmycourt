Do not start with the feature checklist alone

Ask how the vendor handles a weak Tuesday morning, a last-minute cancellation, a 3/4 open match, a dormant high-value player and a booking coming from an external marketplace. Those scenarios expose whether the product only stores data or actually changes operations and economics.

Require evidence and boundaries

Ask which integrations are live, which are read-only, what requires manual work, what data is stored, and how the supplier defines incremental revenue. A credible vendor should be able to explain limitations without hiding behind a feature matrix.
