## Mandatory rules
1. Never redraw, reinterpret or regenerate the F mark or FillMyCourt wordmark.
2. Never use a substitute logo, font-built F, racket icon, padel icon, or AI-invented brand mark.
3. No green/lime brand accents.
4. No metallic/luxury visual direction.
5. No stock racket-sport photography unless explicitly approved for a specific asset.
6. Default visual motif: capacity slots filling; conceptual, not client-result data.
7. Message: **More play. Higher revenue.**
8. Descriptor: **Revenue infrastructure for racket clubs.**
9. Social derivatives must be composed from the canonical master assets, not re-created generatively.
10. If a generative image tool is used for supporting imagery, the canonical logo must be overlaid deterministically afterwards and the tool must not render or modify the logo.

Any visual that violates these rules must be rejected before review.
