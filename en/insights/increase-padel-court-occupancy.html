Occupancy

How to increase padel court occupancy without starting with discounts.

Higher occupancy creates value only when incremental revenue exceeds the incentive cost and does not cannibalise bookings that would have happened anyway.

1. Separate prime time from at-risk inventory

A Tuesday 8pm court and a Tuesday 11am court should not receive the same intervention. Build a daypart occupancy map and identify structurally weak windows first.

2. Work existing demand before buying new demand

Start with players whose past behaviour fits the time, sport, level and booking lead time. Narrow targeting is usually more useful than broadcasting an offer to the whole database.

3. Treat cancellations as perishable inventory

A late cancellation returns capacity to the club. Its value falls as the start time approaches. Use an escalation sequence and increase the incentive only if the first cohort does not respond.

4. Treat incomplete games as commercial risk

In padel, three players without a fourth can mean losing the entire booking. Match formation belongs in the same priority queue as an empty court.

5. Use an incentive ladder

Matching and timing first. Then priority, points, future credit or low-cost perks. Discount only when leaving the court empty is more expensive than giving up margin.

Core metric: net incremental revenue recovered — not occupancy percentage alone.

6. Compare against a baseline

If the slot would have sold anyway, there is no recovered revenue. Record initial risk, intervention, incentive and outcome so the club learns which workflows genuinely work.
